# REPORT · STM32 计算器



## 一、我完成了什么

一台STM32科学计算器。支持四则、括号、幂、科学计数法、三角函数、对数、开方、复数、极坐标运算，复数与极坐标形式相互转换。
作者提供的六个静态库仅保留 `liblcd1602.a`，其余五个库全部重写，将FreeRTOS替换为while（1）轮询，并且将求值器扩展到复数和极坐标。此外，新增了小游戏，历史，格式化，暂存，CGRAM五个模块。

## 二、我学到了什么

### 1.焊接技巧
- 焊接顺序：金贵的后焊，如果先焊排母和芯片，容易在再去焊接其它的东西的时候烫化或吹化塑料
- ttp229芯片焊接可以用锡膏加刀头拖焊，最后用吸锡带处理，即不易连锡又防止芯片被热风枪吹坏
### 2.调试方法
- 硬件 检查接线（比如线要插在stlink的下面那一排），用万用表测是否连锡
- 纯逻辑模块可以脱离硬件单测，某处结果不对时可以写“探针”小程序来看具体是哪个函数。
- 实在不行就问学长，学长是万能的（doge）
### 3.可以先会应用再懂原理
- 先重写函数，让计算器跑起来再去学底层配置才是正确的顺序
### 4.与AI相处之道
- 在什么都不会的情况下完全相信AI自信的说辞是不可取的。额外找教程或多问来验证可以减少被坑的几率。
### 5.注重细节
- 烧完之后不按reset，stlink线插错，代码里面带中文符号，文件命名的格式不对，烧完之后不按reset等等都有可能是排查很久之后才发现的“小错误”
